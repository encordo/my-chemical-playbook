## Pruebas

Instala las dependencias y ejecuta Vitest en modo de una sola ejecución:

```bash
npm install
npm test
```

Para mantener Vitest ejecutándose y volver a ejecutar las pruebas al detectar cambios:

```bash
npm run test:watch
```

Las pruebas están en `tests/` y utilizan el entorno Node.js.
